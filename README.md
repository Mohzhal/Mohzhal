### 👨‍💻 About Me

Software Engineer yang berfokus pada pengembangan solusi **Enterprise Resource Planning (ERP)** berbasis **Frappe Framework & ERPNext**, dengan spesialisasi domain **Manufaktur**, **Inventaris**, dan **Supply Chain**. 

Mengintegrasikan pilar **5M + 1E** (*Man, Machine, Material, Method, Money, & Environment*) ke dalam arsitektur sistem modular: perancangan kustom DocType, optimasi alur kerja lantai produksi (*shop floor*), integrasi multi-tier BOM, serta otomatisasi jurnal finansial secara real-time.

- ⚙️ **Core Focus:** Frappe Framework, ERPNext Manufacturing, Logistics & Inventory Customization.
- 🏭 **Domain Expertise:** Production Planning, BOM Costing Rollup, Job Cards, Workstation Capacity & Traceability.
- 🐧 **Environment:** Linux / WSL, Python, MariaDB / PostgreSQL, REST APIs.
