### 👨‍💻 Tentang Saya

Halo! Saya **Muhammad Rizal**, seorang **Software Engineer** dengan fokus pada **ERP Manufacturing, Inventory, & Supply Chain Development** berbasis **Frappe Framework & ERPNext**.

Saya memadukan framework industri **5M + 1E** (*Man, Machine, Material, Method, Money, & Environment*) ke dalam arsitektur sistem ERP:
- ⚙️ **Kustomisasi DocType & Alur Produksi:** Otomatisasi *Work Order*, *Job Cards*, *Production Plan*, hingga *Shop Floor Tracking*.
- 📦 **Stok & Pelacakan:** Manajemen *Multi-level BOM*, valuasi biaya HPP (*Costing Rollup*), dan *Batch/Serial Traceability*.
- 💻 **Tech & Backend Integration:** Frappe Framework, Python, MariaDB/PostgreSQL, REST APIs pada lingkungan Linux/WSL.
